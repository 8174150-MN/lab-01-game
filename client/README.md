## 1. Порівняння завантаження: Sequential vs Concurrent
* **Послідовне завантаження (Sequential `await`):**
  У випадку послідовного завантаження кожен файл починає завантажуватися тільки після того, як повністю завершиться завантаження попереднього (`await load1(); await load2();`).
  * **Загальний час:** Сума часу завантаження всіх файлів ($t_1 + t_2 + t_3 + \dots$).
* **Паралельне завантаження (Concurrent `Promise.all`):**
  Усі мережеві запити надсилаються одночасно. Браузер завантажує файли паралельно.
  * **Загальний час:** Дорівнює часу завантаження найповільнішого файлу ($\max(t_1, t_2, t_3 \dots)$).
  * **Висновок:** Використання `Promise.all` у `loader.js` суттєво прискорює стартове завантаження гри.

### Головоломка 2: async / await та мікрозадачі
```javascript
async function test() {
  console.log('A');
  await Promise.resolve();
  console.log('B');
}
test();
console.log('C');
```
* **Вивід:** `A`, `C`, `B`
* **Пояснення:** Рядок `A` виконується синхронно, а оператор `await` призупиняє функцію та додає продовження (`B`) у чергу мікрозадач, дозволяючи спочатку виконатися синхронному `C`.

### Головоломка 3: setTimeout всередині .then()
```javascript
Promise.resolve().then(() => {
  console.log('X');
  setTimeout(() => console.log('Y'), 0);
});
console.log('Z');
```
* **Вивід:** `Z`, `X`, `Y`
* **Пояснення:** Синхронний `Z` виконується першим, після чого мікрозадача `.then()` виводить `X` та реєструє нову макрозадачу `setTimeout` з `Y`.

### Головоломка 4: requestAnimationFrame vs Promise
```javascript
requestAnimationFrame(() => console.log('rAF'));
Promise.resolve().then(() => console.log('Promise'));
console.log('Start');
```
* **Вивід:** `Start`, `Promise`, `rAF`
* **Пояснення:** Синхронний код `Start` відпрацьовує одразу, мікрозадача `Promise` виконується негайно після нього, а `rAF` чекає фази перед оновленням кадру браузером.

### Головоломка 5: Поєднання await, .then() та таймерів
```javascript
async function run() {
  console.log('Step 1');
  setTimeout(() => console.log('Timer 1'), 0);
  await Promise.resolve().then(() => {
    console.log('Step 2');
    setTimeout(() => console.log('Timer 2'), 0);
  });
  console.log('Step 3');
}
run();
```
* **Вивід:** `Step 1`, `Step 2`, `Step 3`, `Timer 1`, `Timer 2`
* **Пояснення:** `Step 1` друкується синхронно; мікрозадача `.then()` виводить `Step 2`, а `await` продовжує виводом `Step 3` у мікрозадачах до того, як подійний цикл перейде до черги макрозадач `Timer 1` та `Timer 2`.

## 3. Галерея збоїв (Failure Gallery)

1. **404 спрайта (Файл не знайдено):**
   * **Поведінка:** `fetchWithRetry` перевіряє `status >= 400 && status < 500` і свідомо не робить повторних спроб на помилки 4xx.
   * **Результат:** Гра не падає, перехоплює помилку в `bootstrap()` і виводить екран з повідомленням та кнопкою **Retry**.

2. **Мережевий таймаут (Network Timeout):**
   * **Поведінка:** Запит скасовується за допомогою `AbortSignal.timeout(3000)`, якщо сервер не відповідає протягом 3 секунд.
   * **Результат:** Лобі не зависає назавжди, а продовжує опитувати сервер під час наступного інтервалу.

3. **Abort посеред завантаження:**
   * **Поведінка:** Клік на кнопку "Скасувати" викликає `loadAbortController.abort()`.
   * **Результат:** Усі мережеві запити миттєво перериваються, а гра виводить стан скасування завантаження користувачем.

4. **Битий JSON (Invalid JSON format):**
   * **Поведінка:** Спроба розпарсити некоректний `manifest.json` або `rooms.json` викидає `SyntaxError`.
   * **Результат:** Помилка перехоплюється блоком `try...catch`, запобігаючи збою додатку та пропонуючи спробувати знову.
